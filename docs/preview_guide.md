# ROI 预览与统计图说明

## 统计图状态

第一阶段没有生成柱状图、直方图、散点图、ROC、PR 曲线或训练曲线。因此当前没有带横轴和纵轴的统计图需要解释，也不能从本阶段推断模型性能、置信区间或显著性。

本地生成的 4 张 `contact_sheet_*.jpg` 是 ROI 审计联系表，不是统计图。它们包含 TN5000 图像内容，当前不进入 Git。
